# Учебный центр — платформа для математики и английского

Веб-платформа учебного центра: расписание, журнал посещаемости и оценок, домашние задания и рейтинги учеников и учителей. Три роли: администратор, учитель, ученик. Интерфейс на русском, оформлен как «кабинет старого учителя»: дерево, кожа, бумага, латунь, чернильные штампы.

## Возможности

**Для всех ролей**
- **Ник — главное имя** во всём интерфейсе (3–20 символов, уникален без учёта регистра). Настоящее имя показывается мелко. Фото профиля: с телефона (камера, галерея) или с компьютера, обрезка в круг; без фото — красивая заглушка с буквой ника. Рамка фото и цвет карточки на выбор.
- **Профиль** (`/profile`): каждый правит только свой (ник, имя, «о себе», телефон, почта, дата рождения, пароль). Чужие контакты и даты рождения не показываются никому, кроме владельца и администратора.
- **Мастер первого входа:** новый пользователь входит с временным паролем, выбирает ник, задаёт свой пароль и (по желанию) загружает фото.
- Светлая и тёмная тема («вечерний кабинет»), адаптивная вёрстка для телефонов, планшетов, ноутбуков и мониторов (от 320px), подсказки «?» на непонятных местах, понятные пустые экраны и ошибки, «Сохранено ✓», подтверждение перед удалением.

**Администратор**
- Главная: ученики, учителя, группы, посещаемость, уроки недели, средний рейтинг, группы без учителя, ученики без группы, тревоги безопасности, последние действия, топ-10 учеников, рейтинг учителей (с посещаемостью и долей сданных ДЗ), графики.
- Учителя, ученики, группы, предметы, расписание: создание, изменение, удаление. Правка любого профиля (с записью в журнал), сброс пароля (временный пароль показывается один раз), ручная блокировка и разблокировка.
- **Журнал действий** (`/admin/journal`): кто, что и когда менял; поиск и фильтр.
- **Безопасность** (`/admin/security`) и колокольчик: см. ниже.
- Заметки учителей об ученике — только для чтения.

**Учитель**
- «Сегодня»: уроки дня; «Кому нужно внимание» (низкий рейтинг, пропуски подряд, несданные ДЗ, слабые оценки — с причинами); рейтинг учителя.
- Журнал урока: посещаемость «штампом» в один клик, кнопка «Все пришли», оценки 1–5 с комментариями, тема урока. ДЗ на пробковой доске. Профили своих учеников: ранг, динамика, график, заметки об ученике (видны только автору и администратору).

**Ученик**
- «Моё сегодня»: уроки сегодня, что сдать в ближайшие дни, новые оценки.
- Рейтинг: стрелочный прибор, три шкалы, ранг (Новичок → Ученик → Продвинутый → Отличник → Мастер → Легенда), динамика за неделю, график за 8 недель, место в группе, доска почёта (можно скрыть себя), достижения, подсказки «что улучшить», окно «Как считается рейтинг?». Новый ранг или награда — с конфетти (один раз).
- История оценок с комментариями учителя, календарь посещаемости по месяцам, ДЗ со сроками и статусами («Просрочено», «Сдать сегодня», «Скоро срок», «Сделано») и фильтром, расписание.

**Рейтинг ученика (100 баллов):** успеваемость 50, посещаемость 25, ДЗ 25 (формулы не менялись). **Рейтинг учителя** — средний рейтинг учеников его групп.

## Безопасность

- Пароли хранятся только как bcrypt-хеши. Права проверяются на сервере в каждой странице, действии и API (чужая группа или чужой ученик → HTTP 403). Весь ввод проверяется zod. Вывод экранирует React (HTML из данных не вставляется), к базе — только параметризованные запросы Prisma. Фото перекодируются на сервере (WebP 512×512, метаданные удаляются), принимаются только jpg/png/webp до 5 МБ.
- **Автоматических блокировок нет.** Никто не блокируется за неудачные входы: ни лимитов, ни таймаутов, ни задержек. Вместо этого, когда в один аккаунт **5 раз подряд** ввели неверный пароль, администраторам приходит **уведомление** (колокольчик и страница «Безопасность»: кто, сколько попыток, когда, с какого устройства и IP). Админ сам решает кнопками: **«Всё в порядке»**, **«Сбросить пароль»**, **«Заблокировать аккаунт»** (вручную), **«Разблокировать»**. Все решения пишутся в журнал действий. Серию обрывает успешный вход.

## Стек

Next.js 16 (App Router) · TypeScript (strict) · Tailwind CSS 4 + компоненты shadcn/ui (Radix) · Prisma 6 (SQLite / PostgreSQL) · Auth.js v5 (логин и пароль, bcrypt) · zod · Vitest · Playwright.

## Установка и запуск

Нужен Node.js 20.9 или новее.

```bash
npm install
cp .env.example .env          # затем задайте AUTH_SECRET (npx auth secret)
npm run db:setup              # применить схему (SQLite: prisma/dev.db)
npm run db:seed               # демо-данные
npm run dev                   # http://localhost:3000
```

Продакшен-сборка: `npm run build && npm run start`.

### Переменные окружения (`.env`)

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | `file:./dev.db` (SQLite) или `postgresql://user:pass@host:5432/db` |
| `AUTH_SECRET` | секрет для подписи сессий (обязателен) |
| `APP_TIMEZONE` | часовой пояс центра, по умолчанию `Asia/Tashkent` |
| `SEED_ADMIN_PASSWORD` | пароль `admin` при загрузке сида (по умолчанию `admin123`) |
| `STORAGE_DRIVER` | где хранить фото: `local` (папка `STORAGE_DIR`, по умолчанию `./storage`) или `s3` |
| `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_REGION` | для `STORAGE_DRIVER=s3` (AWS S3, Cloudflare R2, Supabase, Backblaze, MinIO) |

## Демо-логины

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `admin123` |
| Учителя | `teacher1`, `teacher2`, `teacher3` | `teacher123` |
| Ученики | `student1` … `student30` | `student123` |

У демо-пользователей ник уже выбран (его задаёт сид). Новые аккаунты, созданные администратором, при первом входе проходят мастер и выбирают ник сами.

В сиде 3 учителя, 30 учеников, 6 групп (3 по математике, 3 по английскому), расписание, уроки за последние 30 дней с посещаемостью, оценками и ДЗ, поэтому рейтинги считаются сразу. `teacher1` ведёт две группы по математике, `teacher2` — две по английскому, `teacher3` — по одной группе каждого предмета.

> `npm run db:seed` полностью пересоздаёт данные в базе из `DATABASE_URL`.
>
> **Фото на Vercel:** файловая система там не сохраняется, поэтому в облаке задайте `STORAGE_DRIVER=s3` и данные бакета. Локальный режим годится для компьютера и своего сервера.
>
> **Безопасность:** демо-пароли записаны в этом README. На сайте, открытом в интернете, задайте `SEED_ADMIN_PASSWORD` и смените пароли в «Мой профиль» (есть у каждой роли).

| Команда | Что делает |
|---|---|
| `npm run dev` | режим разработки |
| `npm run build` / `npm run start` | сборка и запуск продакшена |
| `npm run lint` | ESLint (0 предупреждений) |

## Переход на PostgreSQL

1. Создайте базу, например `createdb edu`.
2. Укажите в `.env` `DATABASE_URL="postgresql://user:pass@localhost:5432/edu"`.
3. Выполните:
   ```bash
   npm run db:setup   # переключит provider в schema.prisma на postgresql и создаст таблицы (prisma db push)
   npm run db:seed
   npm run build && npm run start
   ```

Скрипт `scripts/db-provider.mjs` сам определяет провайдера по адресу базы. Чтобы вернуться на SQLite, поставьте `DATABASE_URL="file:./dev.db"` и снова выполните `npm run db:setup`. Переход проверен на PostgreSQL 16.

## Деплой

### Vercel + Neon (бесплатно, можно сделать с телефона)

В проекте есть скрипт `vercel-build`, который Vercel запускает сам. Он переключает Prisma на PostgreSQL, создаёт таблицы, загружает демо-данные **только если база пустая** (повторные деплои данные не затирают) и собирает приложение. Командную строку открывать не нужно.

1. Зайдите на **vercel.com** → Sign Up → Continue with GitHub.
2. **Add New… → Project** → выберите репозиторий → **Import**.
3. Откройте **Environment Variables** и добавьте:
   - `AUTH_SECRET` — любая длинная случайная строка (32+ символа);
   - `SEED_ADMIN_PASSWORD` — пароль администратора (иначе будет `admin123`);
   - `APP_TIMEZONE` — `Asia/Tashkent`.
4. Нажмите **Deploy**. Первая сборка остановится с сообщением «DATABASE_URL не задан»: базы ещё нет, так и должно быть.
5. В проекте откройте **Storage → Create Database → Neon (Serverless Postgres)** → Create → **Connect** к проекту. Префикс переменных оставьте по умолчанию: Vercel сам добавит `DATABASE_URL` и `DATABASE_URL_UNPOOLED`.
6. **Deployments** → у последнего деплоя меню «…» → **Redeploy**.
7. Откройте адрес вида `https://<проект>.vercel.app` с телефона и войдите.

После первого входа смените пароли: страница «Мой профиль» (значок с фото в шапке или «Мой профиль» в меню). Пароли учителей и учеников админ меняет в их карточках («Изменить»). Демо-учеников и учителей можно удалить.

SQLite на Vercel не подходит: файловая система там только для чтения и не сохраняется между запусками.

### Свой сервер (VPS)

```bash
npm ci
npm run db:setup && npm run db:seed   # сид — только для демо
npm run build
npm run start -- -p 3000              # за nginx; для постоянной работы — pm2 или systemd
```
На своём сервере можно оставить SQLite: база хранится в `prisma/dev.db` (делайте резервные копии). Можно и PostgreSQL.

## Структура

```
prisma/            схема, миграции, сид
scripts/           переключение провайдера БД
src/proxy.ts       первая линия защиты маршрутов (middleware в Next 16)
src/auth.ts        Auth.js: вход по логину и паролю
src/lib/
  access.ts        серверные проверки ролей и владения данными
  rating.ts        расчёт рейтингов (чистые функции, покрыты тестами)
  rating-data.ts   загрузка данных для рейтинга из БД
  ranks.ts, achievements.ts, leaderboard.ts, rating-history.ts   ранги, награды, доска почёта, динамика
  attention.ts     правила «Кому нужно внимание»
  security-rules.ts, security.ts   серия неудачных входов, уведомления администраторам
  storage/         хранилище фото (папка или S3)
  lessons.ts       генерация уроков из расписания
  validation.ts    zod-схемы всех форм и API
  i18n/ru.ts       все тексты интерфейса
src/app/
  admin/ teacher/ student/   кабинеты ролей
  profile/ welcome/          профиль и мастер первого входа
  actions/                   server actions (admin, teacher, profile, security, auth)
  api/                       API routes с проверкой прав
src/components/    UI (shadcn/ui), общие компоненты, формы
tests/unit         Vitest
tests/e2e          Playwright
```
