# Газ тармоғи гидравлик модели

Гидравлический расчёт газораспределительных сетей по ТЗ АО «Ҳудудгазтаъминот» (2026).
Итог — один файл **`dist/Gaz_tarmogi_modeli.html`** (≈160 КБ): открывается в Chrome на телефоне или ПК,
без сервера. Библиотеки Excel/PDF грузятся с cdnjs, поэтому для кнопок Excel/PDF нужен интернет; расчёт и схема работают и без него.

## Команды
```
npm install          # xlsx, html2pdf.js, playwright (для тестов)
npm test             # тесты ядра T1–T12 (node --test)
npm run build        # сборка dist/Gaz_tarmogi_modeli.html
npm run e2e          # сборка + сквозной тест в Chromium
node build.mjs --inline   # вариант с библиотеками внутри файла (≈1,9 МБ, работает офлайн)
```

## Структура
- `src/engine.js` — ядро: потенциалы узлов, Ньютон + PCG по ступеням, потребление зависит от давления,
  ГРП/ШРП (внешний цикл: модельные проходы + Левенберг–Марквардт), проверки данных, реестр проблем.
- `src/io.js` — Excel: шаблон, импорт (в т.ч. старый формат «Истеъмолчилар» + «Гидравлик ҳисоб»), результаты, «?» для недостающих данных.
- `src/scheme.js` — SVG-схема, масштаб/перетаскивание, PNG для отчёта.
- `src/report.js` — PDF-отчёт (15 разделов §17) и PDF-запрос недостающих данных.
- `src/app.js`, `src/shell.html` — интерфейс; `src/sample.js` — пример сети (§11) и данные Ҳалқобод.

## Отличия от буквального текста ТЗ (осознанные)
- λ в зоне Re 2000–2020 берётся как max(64/Re; 0,0025·Re^0,333), чтобы λ была непрерывной; в остальном формулы СП 42-101 без изменений.
- Расход трубы по Δφ находится точным обращением h(Q)=K·λ(Q)·Q² (а не 6 итерациями), шаг Ньютона — линейный поиск по выпуклой энергии.
- Если у ГРП не задан PinMin, считается Pout ≤ Pin (PinMin = Pset).
- Внешний цикл ГРП/ШРП сходится к |Pout − law(Pin)| ≤ 10⁻⁵·Pset.
- Имена скачиваемых файлов — латиницей (Chrome заменяет кириллические имена на «download»).
